# ferriscms

A 1:1, offline-first clone of [Strapi](https://github.com/strapi/strapi) built entirely in Rust.

- **Backend**: Axum + SeaORM 2.0
- **Frontend/UI**: Dioxus (multiplatform — native desktop + WASM web)
- **Public data access**: REST API (Strapi-compatible shape)

See [docs/00-overview.md](docs/00-overview.md) to get started.
