ferriscms {{ .Chart.AppVersion }} has been installed.

Getting started:
  export SERVICE_NAME=$(kubectl get svc --namespace {{ .Release.Namespace }} -l "app.kubernetes.io/name=ferriscms,app.kubernetes.io/instance={{ .Release.Name }}" -o jsonpath='{.items[0].metadata.name}')

  # Port-forward to the admin/API locally:
  kubectl --namespace {{ .Release.Namespace }} port-forward svc/$SERVICE_NAME 1337:1337

Then open http://localhost:1337/admin/init and register the first admin user.

Set a strong JWT_SECRET in production (--set env.JWT_SECRET=...).
The webserver uses PostgreSQL: point env.DATABASE_URL at your database
(--set env.DATABASE_URL='postgres://user:pass@host:5432/ferriscms').
The PVC mounts at /data for uploaded media only.
